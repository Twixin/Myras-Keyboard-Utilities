# Myra's Keyboard Utilities
I made this to fix a few of my problems and thought i might as well upload it in case i ever lose the file. The scroll wheel on my mouse has been non-functional for some time now and i recently came up with the idea to turn the volume knob on my keyboard scroll instead. I also decided to throw some media control buttons in there because repeatedly tabbing in and out of spotify was starting to annoy me.

This program makes a few of the keys on your keyboard do different things
Volume Up - Scroll Down
Volume Down - Scroll Up
Page Up - Next Song
Page Down - Previous Song
Home - Play/Pause
